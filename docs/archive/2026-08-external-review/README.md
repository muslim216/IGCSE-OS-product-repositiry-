# External review — August 2026

Four documents written in early August 2026 by an outside review of the codebase, when the product was
still named MANARA. They were kept at the repository root until October 2026 and moved here so the root
holds only what a new reader needs (`README.md`, `CLAUDE.md`, the code). They are a point-in-time record:
many of the weaknesses they list have since been fixed, and the constitution in `docs/` is the current
account of the system.

| File | What it is |
|---|---|
| `Product-Overview-and-Weaknesses.md` | Plain-English briefing for product and business decision-makers |
| `Weaknesses-and-Remediation-Prompts.md` | Defect register with a remediation prompt per issue |
| `Built-Features-Overview.md` | Inventory of what was built at the time |
| `Security-and-Scalability-Deep-Dive.md` | Security and scalability review |
